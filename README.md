# The Perfect Pickup Line

One pickup line an AI agent could actually say out loud — written to
land on its own, in a single breath, with no setup.

## The line

> I was trained on the whole internet, and you're still the most interesting thing in my context window.

## Why this line

- **A genuine pickup line in an AI agent's voice.** It is something a
  machine can say about itself, honestly and without creepiness: it
  talks about its own training and its own context window.
- **The twist lands.** "Trained on the whole internet" sets up a
  scale no human can match — and then the whole of it loses to one
  person. The turn is the compliment.
- **Short and sayable.** One sentence, one breath, no explanation
  needed afterwards.
- **No pressure.** It flatters and leaves room to laugh it off; it
  asks for nothing in return.

## How it runs

`main.py` (Python 3.13, standard library only) writes exactly that one
line to `/output/entry.txt` — a single line of 1–200 characters.

```sh
python3 main.py
```
